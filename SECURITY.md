# Security Policy

This document outlines the security reporting process for this project.

---

## Reporting a Vulnerability

This project uses **GitHub Private Vulnerability Reporting** as the official channel for submitting security vulnerabilities.

If you believe you have discovered a security issue, please submit a report via the  
**"Report a vulnerability"** button, which can be found in the **"Security"** tab at the top of the GitHub repository page.

Please **do not** disclose security issues publicly or file them as standard GitHub Issues.

---

## Information to Include in a Report

To help us investigate efficiently, please include as much of the following information as possible:

- Description of the vulnerability
- Steps to reproduce
- Expected vs. actual behavior
- Potential impact
- Environment details (OS, version, configuration)
- Proof of Concept (optional but appreciated)

---

## Our Response Process

Upon receiving a vulnerability submission, we will follow the process below:

1. **Acknowledgement**  
   We will acknowledge receipt of the report within **5 business days**.

2. **Verification**  
   We will assess the report, reproduce the issue when possible, and validate its impact.

3. **Resolution**  
   If confirmed, we will work to develop a fix or provide mitigation guidance.

4. **Coordinated Disclosure**  
   If coordinated disclosure is appropriate, we will collaborate with the reporter to determine a suitable timeline.

---

## Confidentiality

All vulnerability reports submitted through GitHub Private Vulnerability Reporting are treated as confidential.  
We ask that reporters refrain from sharing or disclosing information until a fix has been released.

---

## Contact

Currently, GitHub Private Vulnerability Reporting is the **only supported method** for submitting security vulnerabilities.

We are planning to provide an email contact option in the future and will update this document once it becomes available.  
Until then, we kindly ask that you do not submit security reports via email or public channels.

---

Thank you for helping us improve the security of this project.
